# Telegram-бот для управления задачами

Бот на C# и .NET 8 хранит личные списки и задачи, показывает их по пять на странице, отмечает выполнение и удаляет записи после подтверждения. Навигация через inline-кнопки изменяет текущее сообщение. Выполненные задачи доступны отдельно, с такой же пагинацией.

## Запуск

Нужны .NET SDK 8.0.400 или новее в ветке 8.0 и токен Telegram-бота, полученный у [BotFather](https://core.telegram.org/bots/tutorial#obtain-your-bot-token).

1. Откройте папку решения `ToDoBot.sln`.
2. В PowerShell задайте переменные окружения только для текущего окна:

   ```powershell
   $env:TELEGRAM_BOT_TOKEN = Read-Host 'Токен бота'
   $env:TODO_DATA_PATH = 'data/todo.json'
   dotnet run --project src/ToDoBot
   ```

3. Откройте личный чат с ботом и отправьте `/start`.
4. Для остановки нажмите `Ctrl+C`.

Настройки задаются через переменные окружения. Их названия приведены в `.env.example`.

## Команды и кнопки

| Команда | Действие |
| --- | --- |
| `/start` | Начать работу и показать помощь |
| `/help` | Открыть описание команд и кнопок |
| `/show` | Выбрать список и посмотреть задачи |
| `/addtask` | Выбрать список, ввести название и необязательную дату |
| `/addlist` | Создать список |
| `/deletelist` | Выбрать список и подтвердить удаление |
| `/report` | Посмотреть число активных и выполненных задач |
| `/cancel` | Отменить текущий диалог |

Название списка или задачи занимает от 1 до 120 символов. Для срока используется формат `YYYY-MM-DD`; знак `-` означает отсутствие срока. Время создания показывается в UTC, срок - как календарная дата.

В списке нажмите название задачи, затем **«✅Выполнить»** или **«❌Удалить»**. Перед удалением появятся отдельные кнопки **«Да, удалить»** и **«Отмена»**. Подтверждение одноразовое, связано с пользователем и сообщением и действует десять минут. Переход к другому экрану в том же сообщении отменяет неиспользованное подтверждение. Устаревшая кнопка не удаляет задачу. В карточке выполненной задачи указано время выполнения в UTC.

Стрелки переключают страницы по пять задач. **«☑️Посмотреть выполненные»** открывает выполненные задачи выбранного списка; обратная кнопка возвращает активные. При пустом результате выводится **«Задач нет»**. После удаления элементов недоступный номер страницы заменяется последним допустимым.

Раздел **«📌Без списка»** существует всегда. При удалении пользовательского списка его задачи сохраняются в этом разделе. Бот предназначен для личных чатов: чужие задачи и списки недоступны.

## Сборка и проверки

```powershell
dotnet restore ToDoBot.sln
dotnet build ToDoBot.sln --configuration Release --no-restore
dotnet test ToDoBot.sln --configuration Release --no-build
```

Тесты охватывают callback-данные, разбиение LINQ, хранение JSON, права пользователей, страницы активных и выполненных задач, диалоги, подтверждение и отмену удаления.

## Структура

```text
src/ToDoBot/
  Callbacks/   Форматы callback-данных и строгий разбор
  Handlers/    Команды, страницы, карточки задач и диалоги
  Helpers/     GetBatchByNumber на основе LINQ
  Models/      Неизменяемые модели задач и списков
  Scenarios/   Удаление задачи и списка с подтверждением
  Services/    Интерфейсы и JSON-хранилище
  Program.cs   Настройка бота и последовательное получение обновлений
tests/ToDoBot.Tests/
  ...          Проверки поведения и сохранности данных
```

## Данные

`TODO_DATA_PATH` задаёт путь к файлу задач и списков; по умолчанию используется `data/todo.json` относительно рабочей папки. Запускайте один экземпляр приложения на один файл данных. Для резервной копии остановите бота и скопируйте этот файл.
